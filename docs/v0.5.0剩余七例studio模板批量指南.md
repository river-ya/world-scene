## 4. 提交剩余七例，单并发

使用新 `gallery` 入口；旧 `showcase` 仍保留历史 room 模板，不要用旧入口提交本批。每例一张 4090、96G、8 CPU、上限 4 小时；`3-9%1` 是七个独立任务最多同时一个，`MAX_JOBS=2` 是编译并行度。

```bash
cd /shared/your_user/releases/world_scene-v0.5.0
unset SCENE_ENV SCENE_RUNS SCENE_LOGS SCENE_STATE PYTHON_BIN
source slurm/config.sh

if MEM=96G CPUS=8 MAX_JOBS=2 SEED=0 DEPENDENCY= \
  GALLERY_ARRAY='3-9%1' bash slurm/submit.sh gallery; then
  GALLERY_JOB=$(cat "$SCENE_STATE/gallery.jobid")
  printf '%s\n' "$GALLERY_JOB" > "$SCENE_STATE/gallery-main.jobid"
  for SCENE_INDEX in {3..9}; do
    printf '%s\n' "$GALLERY_JOB" > "$SCENE_STATE/gallery-$(printf '%02d' "$SCENE_INDEX").jobid"
  done
  printf '七例主数组号：%s\n' "$GALLERY_JOB"
  squeue -r -j "$GALLERY_JOB"
  bash slurm/logs.sh "$GALLERY_JOB"
else
  printf '%s\n' '预检或提交失败，不读取旧作业号。'
fi
```

70754 包含模型加载约 63 分钟，七例串行可按约 7–8 小时加排队时间作预算，实际以运行记录为准。无需全程保持 SSH；不需要重新提交 check，也不使用过期依赖号。排队时无日志是正常情况，不要重复提交主数组。

## 6. 仅重提实际失败索引（可选）

以下仅举例：只有 4、7 失败且确需重试时才执行；若失败的是其他索引，数组参数和循环中的数字必须同步替换。新作业不覆盖旧失败结果，`gallery-main.jobid` 保留主数组号，单例状态记录实际重试数组号。

```bash
if MEM=96G CPUS=8 MAX_JOBS=2 SEED=0 DEPENDENCY= \
  GALLERY_ARRAY='4,7%1' bash slurm/submit.sh gallery; then
  GALLERY_RETRY_JOB=$(cat "$SCENE_STATE/gallery.jobid")
  for SCENE_INDEX in 4 7; do
    printf '%s\n' "$GALLERY_RETRY_JOB" > "$SCENE_STATE/gallery-$(printf '%02d' "$SCENE_INDEX").jobid"
  done
  printf '重试数组号：%s\n' "$GALLERY_RETRY_JOB"
  bash slurm/logs.sh "$GALLERY_RETRY_JOB"
else
  printf '%s\n' '重试提交失败，保留之前的状态记录。'
fi
```

若只是画面不好而执行成功，保留缺陷记录；同种子原样重跑不作为质量修复办法。

## 7. 七例完成后在服务器导出

按每例状态文件构造真实路径，支持部分任务用新数组号重试。全部 `complete` 且产物摘要通过才会导出；不覆盖已有同名归档。失败日志会随该版本日志目录保留。

```bash
(
  set -euo pipefail
  cd /shared/your_user/releases/world_scene-v0.5.0
  unset SCENE_ENV SCENE_RUNS SCENE_LOGS SCENE_STATE PYTHON_BIN
  source slurm/config.sh
  GALLERY_MAIN_JOB=$(cat "$SCENE_STATE/gallery-main.jobid")
  SCENE_NAMES=()
  for SCENE_INDEX in {3..9}; do
    SCENE_CASE=$(printf 'gallery-%02d' "$SCENE_INDEX")
    SCENE_JOB=$(cat "$SCENE_STATE/$SCENE_CASE.jobid")
    [[ "$SCENE_JOB" =~ ^[0-9]+$ ]]
    SCENE_NAMES+=("$SCENE_CASE-$SCENE_JOB-$SCENE_INDEX")
  done
  "$PYTHON_BIN" -B tools/export_results.py \
    --runs "$SCENE_RUNS" --logs "$SCENE_LOGS" --names "${SCENE_NAMES[@]}" \
    --output "$DATA_ROOT/exports/world_scene-v0.5.0-rest-$GALLERY_MAIN_JOB.tar.gz"
)
```

## 8. 本地下载、摘要校验及解压

输入主数组号，即 `gallery-main.jobid` 中的数字，不填重试数组号，也不填完整归档名。

```bash
(
  set -euo pipefail
  cd /path/to/project
  read -r -p '输入七例主数组号（仅数字）：' GALLERY_MAIN_JOB
  if [[ ! "$GALLERY_MAIN_JOB" =~ ^[0-9]+$ ]]; then

    exit 2
  fi
  SCENE_ARCHIVE="world_scene-v0.5.0-rest-$GALLERY_MAIN_JOB.tar.gz"
  mkdir -p 实验结果
  rsync -av --partial --progress -e 'ssh -p 22' \
    "your_user@your.cluster.example:/shared/your_user/exports/$SCENE_ARCHIVE" \
    "your_user@your.cluster.example:/shared/your_user/exports/$SCENE_ARCHIVE.sha256" \
    实验结果/

  mkdir -p "${SCENE_ARCHIVE%.tar.gz}"

```
