# v0.8.0 本地验证记录

日期：2026-10-23。测试对象：同图 30/45/75° 生成输入、FlashWorld 相机计算与 Slurm 新阶段。

## 已执行

- 独立临时 CPU 环境：Python 3.12、torch 2.6.0+cpu、NumPy 1.26.4、Pillow 10.1.0、plyfile 1.0.3；没有修改集群环境或项目运行依赖。
- 完整 unittest：47 项全部通过，无跳过。覆盖真实冻结图片、相同图文/裁剪/内参、单调左转且无俯仰/滚转变化、固定中心、输入快照不覆盖、非法任务选择拒绝。
- 调用固定 FlashWorld 源码的实际归一化、密集相机插值和 create_rays；验证 24 个生成相机与 346 个视频相机每 15 帧对应一致，旋转方向为输入相机局部左侧。
- 实测末端 yaw：30.0000038°、44.9999962°、75.0°；最大归一化平移残差小于 1e-7；三档导出参考尺度均为 3.4818353653。
- 负向检查：改变位置或伪造目标角度会被 runtime_check 拒绝。
- Slurm 模拟：将 job.sh 复制到独立 spool 路径后执行；angles 默认数组 0-2%1、75° 档运行名及准备命令正确。预检失败或错误 seed 不调用 sbatch，旧作业号不更新；临时输入目录自动清理。
- 全部 Slurm 脚本及新指南的 10 个 Bash 代码块通过语法检查。核对本地 71013 七例的原输入与当前 gallery 配方：图文及元数据相同，相机浮点最大差异约 1.11e-16（跨 Python 环境的舍入差异），不是输入文件字节级相同的声明。

本地使用的 CPU 环境仅用于验证，不上传集群。完整执行命令见 [v0.8.0 指南](v0.8.0同图多角度执行指南.md)。
