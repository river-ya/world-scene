# v0.3.0 同图小范围视角对照

本次只新增一个厨房推理任务，与已有 `showcase-02-70462-2` 对比，不重跑旧基线、不继续其余七例。这里是推理实验，没有训练步骤。预计可参考旧例约一小时，但小视角不减少模型帧数，实际耗时仍须实测。

## 1. 对照条件

| 条件 | 旧例 70462 | 新例 kitchen-small |
|---|---|---|
| 图片、文本、seed、权重、精度、offload | 原记录 | 相同，seed 0；基线输入摘要强制校验 |
| 分辨率 / 相机数 / 输入锚点 | 704×480 / 24 / index 3 | 相同 |
| 内参及裁剪 | 官方模板假设内参，左右约 1% 裁剪 | 相同，仍非真实标定 |
| 相对输入视角旋转 | 最大约 143.4° | 局部 yaw −5° → 0° → +5° |
| 相对输入相机移动 | 原模板 | 局部横向 −0.1 → 0 → +0.1 模型单位 |
| 归一化参考 | 轨迹自身最大平移 | 固定为旧模板尺度，防止短轨迹被重新放大 |

不把模型单位写成米或厘米。相机条件包含位姿及参考尺度，不能把本次对照解释成只改变某一轴。上游源码、模型结构、权重和依赖没有修改。新协议使版本升为 v0.3.0，不覆盖 v0.2.0。

## 3. 服务器导入与预检

先查看旧任务。当前对照不要求取消其他作业；使用共享资产回执的旧版本任务结束后，再刷新回执。保持 96G：旧 64G 已实际 OOM，缩小相机范围不等于模型内存变小。

```bash
squeue -u "$USER"
```

旧版本任务结束后执行：

```bash
(
  set -euo pipefail
  cd /shared/your_user/releases
  sha256sum -c world_scene-v0.3.0.tar.gz.sha256
  if [[ ! -e world_scene-v0.3.0 ]]; then
    tar -xzf world_scene-v0.3.0.tar.gz
  fi
  cd world_scene-v0.3.0
  if [[ ! -e local.env ]]; then
    printf '%s\n' \
      'export SCENE_ENV=/shared/your_user/envs/world-scene-0.1.1' \
      'export MAX_JOBS=2' > local.env
  fi
  unset SCENE_ENV SCENE_RUNS SCENE_LOGS SCENE_STATE PYTHON_BIN
  source slurm/config.sh
  python3 -B tools/experiment.py inspect
  # 发布版本改变了锁文件摘要，完整校验刷新回执；不要手改回执。
  "$PYTHON_BIN" -B tools/assets.py verify --root "$SCENE_ASSETS" --group models
  "$PYTHON_BIN" -B tools/experiment.py preflight
  "$PYTHON_BIN" -B tools/viewcheck.py verify --assets "$SCENE_ASSETS" --runtime
)
```

预检应看到 `OFFLINE_PREFLIGHT_OK`、两行 `CAMERA_BOUNDS_OK`、`CAMERA_EXPORT_SCALE_OK` 和 `VIEWCHECK_INPUT_OK`。相机检查在 CPU 上调用固定上游的真实张量函数及密集插值，不加载模型权重。若失败，停止提交并保留完整报错，不绕过检查。

## 4. 只提交一个小视角任务

```bash
cd /shared/your_user/releases/world_scene-v0.3.0
unset SCENE_ENV SCENE_RUNS SCENE_LOGS SCENE_STATE PYTHON_BIN
source slurm/config.sh

if MEM=96G CPUS=8 MAX_JOBS=2 SEED=0 DEPENDENCY= \
  bash slurm/submit.sh viewcheck; then
  VIEW_JOB=$(cat "$SCENE_STATE/viewcheck.jobid")
  printf '小视角作业号：%s\n' "$VIEW_JOB"
  squeue -j "$VIEW_JOB"
  bash slurm/logs.sh "$VIEW_JOB"
else
  printf '%s\n' '预检或提交失败，不读取旧作业号。'
fi
```

单 GPU、96G、8 CPU，默认 GPU1、4 小时上限。`MAX_JOBS=2` 是扩展编译并行度，不会提交两个推理任务。没有日志通常表示尚未启动；不要因此重复提交。`SEED` 非 0 会被拒绝。旧 check 作业号不用作依赖。

## 7. 本地下载、校验、解压

这里仅输入数字作业号，自动拼接完整归档名，避免漏输 `.tar.gz` 后直接退出。

```bash

  cd /path/to/project
  read -r -p '输入小视角作业号（仅数字）：' VIEW_JOB
  if [[ ! "$VIEW_JOB" =~ ^[0-9]+$ ]]; then

    "your_user@your.cluster.example:/shared/your_user/exports/$SCENE_ARCHIVE" \
    "your_user@your.cluster.example:/shared/your_user/exports/$SCENE_ARCHIVE.sha256" \
    实验结果/

    "$PWD" "${SCENE_ARCHIVE%.tar.gz}" "$VIEW_JOB"

```

## 8. 视觉比较与清理

先对比输入锚点附近（视频约 3 秒，第 45 帧）：地板是否仍被新增桌台遮住，右侧橱柜、窗户、灶台的布局是否保留。再看全片是否仍有漂浮碎片、闪烁、穿透、表面断裂。旧例转角大、新例转角小，不能仅凭新视频后半段看不到破洞就宣称几何修好了；优先比较共同输入视角的保持。

保留旧 70462 和新结果，即使新版仍失败。不要覆盖原始视频、删掉失败记录或把单次改善说成大范围补全成功。本次不训练、不换模型、不改文本、不搜索随机种子。

作业正常退出自动删除它自己的临时输入。若存在异常退出遗留，只清理已结束任务的临时目录。工具在用户仍有任何排队/运行作业时拒绝执行删除。

```bash
cd /shared/your_user/releases/world_scene-v0.3.0
unset SCENE_ENV SCENE_RUNS SCENE_LOGS SCENE_STATE PYTHON_BIN

```

本次不新增模型依赖，不需要删除旧环境、权重、版本、实验结果或编译缓存。没有单独待清理的训练 checkpoint。
