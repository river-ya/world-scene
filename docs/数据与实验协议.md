# 数据与实验协议

依据 [FlashWorld 论文](https://arxiv.org/abs/2510.13678)验证图像和文本到显式三维高斯的任务匹配，以 [WorldScore](https://arxiv.org/abs/2504.00983)的可控场景生成评估组织数据，后续使用 [DL3DV](https://arxiv.org/abs/2312.16256)多视角真实场景检查观测一致性。数据规模与划分是本项目的小样本协议，不是论文官方分数复现。

## 连通验证与提示词对照

v0.1.1 自动运行官方样例 3（室内起居空间）和 5（设备室内场景），每个场景分 B0 空文本、B1 官方描述，共四个独立单卡作业。两组均有输入图像，相机、分辨率和种子相同。模型内部还会加入官方 `[Static]` 提示，因此 B0 准确含义是“无用户描述”，不能叫无任何文本条件。

这些官方样例只用于连通验证和初步对照，不计为独立泛化测试。对照只反映这两个场景及该种子；模型未保证所有 CUDA 操作完全确定性。

## WorldScore 子集

从锁定的官方原始 ZIP 读取 `static/static.json`，过滤 `scene_type=indoor`、`visual_movement=static`、`visual_style=photorealistic`，保留 `content_list` 不改变房间的条目。按原始 image 路径去重，类别轮询，类别内按固定字符串与图像路径的 SHA256 排序，选前 6 个作开发，后 12 个作保留测试。去重确保源图像不同，不代表拥有额外真实空间身份标注。训练数据重叠风险尚不能排除。

固定清单见 `configs/data/worldscore-indoor-v1.json`；资产目录同时保存相同 manifest 和 18 张图像。不得根据生成效果删换测试图像。需要人工检查画面是否满足室内范围，发现源数据问题必须记录和升级子集版本。

原 WorldScore 使用符号相机动作，FlashWorld 需要数值相机参数，冻结的原始清单仍保留 `camera_adapter=pending`。v0.2.0 新增独立展示协议，使用明确记录的假设相机模板及裁剪内参映射，不改写原始清单、不宣称执行了原 WorldScore 动作或真实相机标定。具体约定见 [十案例指南第 2 节](v0.2.0十案例展示执行指南.md)。该选择涉及视角范围与几何尺度，需要与用户确认，再单例试跑；本版没有实现冻结子集的正式评分。

```bash
python3 -B tools/data.py --root ../world_scene_assets
```

该命令只提取选中的 18 张图像，原始 ZIP 留作来源和复现材料；不解压全部数据。

## DL3DV

固定候选来源为 [DL3DV-Evaluation](https://huggingface.co/datasets/DL3DV/DL3DV-Evaluation)，当前需要在官方页面接受访问条款，可能要求向数据方分享联系方式；脚本不代替用户同意。先选室内场景、固定输入帧与保留视角，再决定下载条目。完整评估集体量大，当前不下载全部，也不预设其全为室内。

DL3DV 的保留真实视角可评估已观察区域与真实视图的一致性；允许生成的不可见区域不能一概用像素误差判为错误。PSNR/SSIM/LPIPS 需要相机与渲染对齐，不能对任意生成镜头直接计分。

## 验收记录

每个完成的推理自动保存 PLY/SPZ/MP4 摘要、输入、环境、运行时间（包括模型加载）、显存峰值和版本。自动结构检查通过后仍需人工视觉验收：

1. 输入可见物体、布局和外观是否基本一致；文字引入了什么变化。
2. 在生成区域内平移、旋转视角时是否存在明显破洞、漂浮、重复物体、深度次序错误。
3. 网页和 Blender 插件能否打开同一 PLY 并渲染连续镜头；普通 PLY 点云导入不算 3DGS 渲染通过。
4. 标注生成范围和失效视角；不把相机视频当作物体运动或未来预测。

后续动态研究需另定动作、状态表示、时间序列监督与预测指标。当前训练代码未公开验收，不写虚构的四卡训练命令。

新轨迹沿输入相机局部横轴从 −0.1 经过 0 到 +0.1 模型坐标单位，局部 yaw 从 −5° 经过 0 到 +5°，锚点为第 3 个零基索引相机。前 3 段与后 20 段的移动速度不同，这是保留原锚点时刻的结果。参考尺度固定为旧官方轨迹的最大平移长度，显式通过现有 T_norm 参数传入；不让短轨迹自归一化后重新放大。生成和渲染用同一参考，资产保留正尺度。

这是一次“相机条件整体”的诊断对照，不能据此分别归因于平移或旋转；不是仅修改浏览器视角或裁掉旧视频。小角度本身也会让缺陷更难显露，因此先检查约 3 秒的输入锚点是否仍新增台面、破坏地板，再评估轨迹内几何稳定性。通过仅说明小范围条件改善，不证明大角度补全能力恢复。

模型、权重和数据选择沿用既有 FlashWorld / WorldScore 论文依据；±5° 和 ±0.1 是本项目待检验的诊断参数，并非论文推荐值。未使用保留测试集，未启动微调。完整执行见 [v0.3.0 指南](v0.3.0同图小范围视角对照.md)。
