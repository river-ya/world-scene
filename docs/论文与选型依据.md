# 论文与选型依据

核查日期：2026-10-16。优先采用论文、作者仓库及官方数据页面。下表区分论文能力、公开实现与本项目待验证事项。

## 1. 模型证据

| 论文/方法 | 任务及本项目用途 | 开放状态与验证边界 |
|---|---|---|
| [FlashWorld](https://arxiv.org/abs/2510.13678) | 图文条件三维场景生成；优先基线 | [作者仓库](https://github.com/imlixinyang/FlashWorld)、[权重](https://huggingface.co/imlixinyang/FlashWorld)可查。训练代码需表单申请。当前仓库的静态生成不支持直接声称动作预测 |
| [HunyuanWorld 1.0](https://arxiv.org/abs/2507.21809) | 图文→全景代理→分层三维；备用比较 | [官方仓库](https://github.com/Tencent-Hunyuan/HunyuanWorld-1.0)提供推理、权重链接和浏览器查看工具。完整几何范围及导入效果待测 |
| [Scene Splatter](https://openaccess.thecvf.com/content/CVPR2025/html/Zhang_Scene_Splatter_Momentum_3D_Scene_Generation_from_Single_Image_with_CVPR_2025_paper.html) | 单图生成新视角并更新高斯场景；渐进扩展参考 | [作者代码](https://github.com/shengjun-zhang/Scene-Splatter)依赖其他公开模型，环境复杂度高于单一入口 |
| [ViewCrafter](https://arxiv.org/abs/2409.02048) | 单/稀疏视角生成；作为相关方法调研 | [官方实现](https://github.com/Drexubery/ViewCrafter)的新视角视频不能直接替代本项目三维资产交付 |
| [HY-World 2.0](https://arxiv.org/abs/2604.14268) | 多模态世界生成与重建；较完整系统的调研对象 | [官方实现](https://github.com/Tencent-Hunyuan/HY-World-2.0)中不同分支的资源要求需分别核验 |
| [PhysDreamer](https://arxiv.org/abs/2404.13026) | 从生成视频先验获得三维交互动力学 | [官方项目](https://physdreamer.github.io/)；主要用于后续动态研究设计，未验证与本基线兼容 |
| [PhysGaussian](https://github.com/XPandora/PhysGaussian) | 高斯表示与物理仿真结合 | 可作未来物理对照，不能将仿真运行等同于学习式状态预测 |
| [PhysTwin](https://arxiv.org/abs/2503.17973) | 从动态视频估计物理表示并预测新交互 | 需要动态观测，输入条件超出第一阶段单图生成 |

## 2. 为什么提出这些数据

FlashWorld 论文附录列出 RealEstate10K、DL3DV10K、MVImgNet 等训练数据。这支持“室内单图条件＋多视角监督/评测”的数据形式；本项目不需要照搬全部数据或预训练规模。[论文附录](https://arxiv.org/html/2510.13678v1#A1)。

- [WorldScore 论文](https://arxiv.org/abs/2504.00983)与[官方代码](https://github.com/haoyi-duan/WorldScore)：用于世界生成评估，选室内静态子集并公布筛选规则。任务子集与完整榜单分开报告。
- [DL3DV-10K 论文](https://arxiv.org/abs/2312.16256)与[官方数据仓库](https://github.com/DL3DV-10K/Dataset)：有场景环境标签及相机参数，适合筛选室内与评估视角变化。优先申请[独立评测集](https://huggingface.co/datasets/DL3DV/DL3DV-Evaluation)，无需全量下载。
- [RealEstate10K 官方说明](https://google.github.io/realestate10k/)：房产视频相关相机轨迹数据，适合作为室内候选；获取原始视频与具体预处理版本需另行核实。
- 旧项目中桌面操作数据可以留作历史实验资产；它不作为室内场景补全主数据。第一阶段不继续沿用其动作标签与模型目标。

## 3. 已核对的 FlashWorld 实现

代码版本：`424db4487de308a39e5137afbe85e7568a96193f`。

| 项目 | 核查结果 |
|---|---|
| 图文联合输入 | `cli.py` 将图像及文本一起传给 `GenerationSystem.generate` |
| 三维输出 | CLI 支持 PLY/SPZ；MP4 是附加渲染结果 |
| 静态约束 | `app.py` 在文本前添加 `[Static]` |
| 模型加载 | 先加载 Wan 组件，再加载 FlashWorld 适配后的主干和三维解码器 |
| 首个室内连通测试 | 官方 `examples/3.json`，另一个室内示例为 `5.json` |
| 输入裁剪 | CLI 会中心裁剪并更新相机内参；评测应保留这个变换 |
| 随机种子 | CLI 无显式 seed 参数；手册提供外层种子设置，不能保证所有 GPU 算子逐位确定 |
| 权重路径 | 手册使用 `--ckpt` 明确传入，避免依赖 CLI 内部写死的缓存快照路径 |

## 4. 展示兼容性

[KIRI 3DGS Render](https://github.com/Kiri-Innovation/3dgs-render-blender-addon)可导入三维高斯 PLY 并参与 Blender 渲染，作为推荐验证工具。应选择与本机 Blender 对应的[发布版本](https://github.com/Kiri-Innovation/3dgs-render-blender-addon/releases)，记录版本并用基线导出资产实测，不假定所有 PLY 都一致兼容。

3DGS 的位置、缩放、旋转、不透明度及颜色字段要保留。将它按普通点云导入、改名为 GLB，或仅输出旋转视频，都不能替代高斯场景本身。
