# v0.7.0 本地验证记录

日期：2026-10-22。本地为 WSL，GPU 是 GTX 1650 Ti 4GB。没有自动登录集群、安装远端环境或提交第二模型任务。

## 已完成

1. 在独立临时 Python 3.9.25 环境安装 torch 2.0.1+cpu 与本版 Python 依赖，依赖兼容检查通过；diffusers、transformers、gradio、open3d、cv2、timm 实际导入通过。解析出的依赖版本写入 `constraints-lucid-py39.txt`，CUDA torch 与编译器由服务器单独安装。
2. **43 项 unittest 通过，无跳过**：既有 36 项回归测试及 7 项第二模型测试。覆盖十个真实案例、逐像素裁剪一致性、GL/CV 转换、实际固定 FlashWorld 相机函数的归一化结果、锚点及密集路径、含非中心主点的投影、资产回执缺项/文件变化拒绝、成功重试路径导出、提交失败不覆盖状态、模拟 Slurm spool 路径运行及临时目录清理。
3. `tests/lucid_cpu_probe.py` 通过三项 CPU 集成检查：
   - 使用实际 diffusers 0.23.1 小型随机权重网络，在禁网条件下保存并加载本地 fp16 命名变体，执行两步非方形 inpainting，确认适配后的 RGB 入口输出正确尺寸。
   - 实际构建本地 ZoeDepth/MiDaS 架构，参数量 344,816,746；无下载初始化代码或权重。
   - 使用合成 RGB/深度执行作者实际矩形点云生成及对齐函数，获得有限点云与十个对齐视图。
4. 所有新增 Python 文件语法检查、Slurm Bash 脚本语法检查、执行手册 18 个 Bash 命令块语法检查通过。
5. LucidDreamer/MiDaS/GLM 源码摘要清单验证通过。SD 固定 revision 的 15 个文件元数据已核查，合计 2,742,246,506 字节。ZoeDepth 首次下载回执策略明确记录，不伪称预先取得作者摘要。

CPU probe 为导入提供 CUDA 扩展占位符，并屏蔽一次导入阶段的 `.cuda()`；占位符一旦被执行即抛错。这些测试**没有执行 CUDA 栅格化、没有加载完整预训练权重，不是 GPU 效果验证**。矩形 inpainting 使用的是小型随机网络，不能用于评价生成质量。

## 可重复的本地检查入口

以下命令在具有对应依赖的独立环境执行；默认系统 Python 缺 numpy/Pillow/torch 时，相机数值测试会显式跳过。

```bash
python -B -m unittest discover -s tests -v
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -B tests/lucid_cpu_probe.py
python -B tools/lucid_assets.py source-check
for LUCID_SCRIPT in slurm/lucid/*.sh; do bash -n "$LUCID_SCRIPT" || exit 1; done
```

本地验证所建临时环境、源码克隆、下载缓存与解包目录在发布验收后清理；发布包只携带运行源码、许可证、锁文件和文档，不携带临时测试网络或完整模型权重。
