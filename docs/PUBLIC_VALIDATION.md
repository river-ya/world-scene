# 公开整理版验证范围

公开版 v0.8.1 源自内部实验版 v0.8.0，来源提交见 `configs/publication.json`。该目录与原运行目录独立；本次只调整公开打包、通用配置与文档，不重新训练或更换模型。

## 检查方式

1. 两套模型源码的固定文件摘要检查；补齐的 simple-knn 许可证独立检查来源与 SHA256。
2. 公开目录检查：排除模型/场景输出、私有配置、缓存、符号链接和超出源码预算的大文件；扫描常见凭据格式及个人集群路径。这是模式扫描，不是对一切潜在隐私或凭据的绝对保证。
3. Python 单元与 CPU 相机/调度测试；Slurm 模拟额外检查空 account、QOS、node 不生成对应命令行选项。
4. Bash 脚本和当前公开手册的语言代码块语法检查；发布压缩包独立解压验证和篡改拒绝检查。

完整测试需要 NumPy、Pillow、plyfile、torch 和已经下载的冻结开发图片。默认 CI 不下载这些大资产，部分检查会标记 skipped；应查看测试日志而非仅看成功退出码。

GPU 环境仍以实际集群 check 和单例推理为准。该公开整理版未向远端提交作业，不能把历史 GPU 结果标为 v0.8.1 新实测。新三档角度与 LucidDreamer 完整 GPU 效果仍待验收。
